Install

Runs on hardware you already have.

Prism is a set of Docker containers. Pick the way that suits you; each takes a few minutes.

Home Assistant add-on

No terminal. Add the repository in the add-on store and press Install.

Docker

Pull the pre-built image on any Linux machine, NAS or Raspberry Pi 4.

Build it yourself

git clone https://github.com/sandydargoport/prism.git
cd prism && bash scripts/install.sh

Before you install

Plain answers.

What does it cost?

Nothing. There is no paid tier, no subscription and no account to make.

Where does my family's data live?

On your own machine, in a Postgres database next to the app. Settings > Backup exports it.

What does it connect to?

Only the services you switch on (calendars, photos, weather, grocery), plus one anonymous weekly update check you can turn off. What it sends.

What is the licence?

Free for personal and non-commercial use under PolyForm Noncommercial 1.0.0. You can run it, change it and share it; you cannot sell it or run it as a paid service.

What if the project stops?

Your install keeps working. It does not depend on any server of ours, and the data is in a standard database you own.

What screen do I need?

Anything with a web browser: a wall-mounted TV or monitor, a tablet, or a phone, where it installs as an app.
